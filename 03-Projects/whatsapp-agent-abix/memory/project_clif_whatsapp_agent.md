- **Hard-won n8n lessons for next time:** (a) PUT-updating an *active* workflow via the public API silently 400s — always deactivate → PUT → reactivate. (b) The HTTP Request node's `jsonBody` expression throws a silent/opaque `"invalid syntax"` ExpressionError when given a large inline nested-object literal inside `={{ }}` — always build the payload object in a preceding Code node and reference it with a trivial `={{ $json.thePayload }}` instead. (c) A Postgres "Execute Query" node's output *replaces* `$json` with just the query result — anything downstream needing the original fields must reference `$('NodeName').item.json...` explicitly, or insert a merge/Code node right after the Postgres node. (d) Never build a fresh payload script against a stale locally-cached workflow JSON — always re-`curl` the workflow immediately before each edit script, or an earlier fix gets silently reverted.
