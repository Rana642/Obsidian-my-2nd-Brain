Never write "dealer", "dealers" or "dealership" in any post, caption, headline, calendar, brief or copy, for any project. Always use "distributor" / "distributors" / "distributor network", and "Become a Distributor" for recruitment.

**Why:** Shoaib, 2026-10-05: "Dealer Words kabhi nai use kerna hamesha distributor ya Become a Distributor yeah".

**How to apply:**
- The KB global rule `no-dealer-word` and the MCP server instructions (b9fccda) carry the rule.
- All existing KB docs were converted the same day: 18 docs, including Tad and Meezab Day 27 "Become a … Distributor".
- When converting, avoid doubles ("distributors and dealers" → "distributors").
- Urdu ڈیلر is banned too. Ask Shoaib for the Urdu word if one is needed.
