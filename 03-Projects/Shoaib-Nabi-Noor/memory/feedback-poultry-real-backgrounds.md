Every product post for a poultry / animal-health client gets a REAL, photo-real poultry background chosen from the product's own topic. A plain studio stage, a flat teal tile or floating bubbles is not enough. Each post also uses a different composition, so the grid has variety.

Examples:
- **Water / diuretic:** broilers at nipple drinkers.
- **Liver / mycotoxins:** broilers eating fresh feed.
- **Gut / FCR:** heavy healthy broilers.
- **Respiratory:** an airy ventilated house.
- **Heat stress:** summer, drinkers and water drops.
- **Vitamins / eggs:** layer hens with egg trays, or chicks in a hatchery.
- **Fertility:** a breeder flock with rooster and hens.

**Why:** Shoaib, 2026-10-06, after the first Meezab Nano Banana test (a teal tile, no poultry): "Products K hisab se Pichy Real poultry k Back Ground any chaiye jisse presentation behter ho wohi Tad pharma aur reef co ki ya unse bhi behter Verstality veriety lao thori". Before that he asked "layout batao kaisa ho ga". He wants to see the layout plan before anything is spent.

**How to apply:**
- Before generating, show free code wireframes. For Meezab: scratchpad `tadstyle/mz-wireframes2.cjs`, output in `meezab-social/product-posts/wireframes/`.
- Get approval, including the spend ([[feedback-ask-before-spend]]).
- Pass the wireframe as the layout concept, with the real pack photo.
- Locked items stay fixed: text, pack, logo, footer and vet line.
